# Logo

`untangle-mark.svg` is a single thread that loops once, then runs straight: a tangle resolving into a line. It is drawn in one ink, `#17142b` (the light-theme `ink` token). SVG shows through `<img>` only, so it cannot inherit colour: on dark grounds use the mark on an `ink-inverse` tile, or redraw the same path with `stroke` set to the dark-theme `ink`.

Clear space: one stroke width x 3 on every side. Minimum size 20px. Beside the mark, the name is set as plain type: Schibsted Grotesk 700, `-0.02em`, written "Untangle".
